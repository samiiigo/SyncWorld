# Run and Test

- Install dependencies with `npm install` inside `syncworld-app`.
- Start Expo with `npm start`.
- Use `npm run web` for browser testing.
- Use `npm run android` or Expo Go for device testing.
- If the iPhone camera says no data, scan from Expo Go or use `npx expo start --tunnel`.
- Run `npm run typecheck` to check the TypeScript scaffold.
